# Changelog

## 1.0.0

- Added Vue 3 phone mask input with `libphonenumber-js` country-aware formatting.
- Added strict default international formatting and optional per-country visual masks.
- Added `v-model:country`, `defaultCountry`, `allowedCountries`, validation metadata, readonly and invalid states.
- Added optional country flag rendering, custom flag URL resolver, and built-in country selector.
- Added selector localization, custom option slot, keyboard navigation, and SSR/Nuxt-safe behavior.
- Added CSS variable styling API and package CSS export through `phone-mask/style.css`.
- Added unit tests, Playwright demo smoke tests, Nuxt consumer smoke, and package dry-run checks.
